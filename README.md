# noru-tech/homebrew-tap

Homebrew formulae for [Noru](https://github.com/noru-tech) command-line tools.

```bash
brew install noru-tech/tap/fl
```

| Formula | Tool | Source |
| --- | --- | --- |
| `fl` | CLI toolbox for the IAB Tech Lab Privacy Taxonomy (Fideslang) and Fides manifests | https://github.com/noru-tech/fideslang-tools |

Formulae under `Formula/` are generated and pushed automatically by
[cargo-dist](https://opensource.axo.dev/cargo-dist/) from each tagged release of the source
repository. Please open issues against the tool's own repository, not here.
